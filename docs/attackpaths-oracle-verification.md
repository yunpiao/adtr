# 合成路径的独立算法校验

关联 [Issue #298](https://github.com/yunpiao/adtr/issues/298) 和
[#44 / AD-F-117](https://github.com/yunpiao/adtr/issues/44)。本切片为已有
[合成路径契约](simulated-attack-path-contract.md)补充独立算法验证，不新增攻击
规则、真实权限、因果或可利用性判断，不改变生产算法、解析器或预算。

## 为什么需要另一套算法

生产 `Graph.Shortest` 使用排序邻接表、FIFO 队列及已访问节点集合。
新增 `internal/attackpaths/oracle_test.go` 属于外部 `attackpaths_test` 包，
只调用公开 API，不读取内部图结构或复用生产遍历函数。

参照实现枚举全部简单有向路径：最短无权路径不需要重复节点，因此可以完整
覆盖所生成小图的最短候选。候选先比较边数，再按契约逐边比较目标节点ID、边ID，
选出确定的同长路径。另用 Floyd–Warshall 距离矩阵独立校验枚举所得最短距离。
两套参照算法必须先相符，才能与生产结果比较；没有把生产结果当成预期值。

规则标签用线性集合查找筛选，时间按 `[Start,End)` 比较。若目标在深度范围内可达，
返回其最短路径；否则，只要存在最短距离大于深度上限的可达节点，就必须为
`ErrLimit`，不能返回完整搜索后的“无路径”。参照同时核对完整节点/边值、来源标签、
空数组形状，以及错误时必须为零结果。这里只验证已声明的合成工程契约，
不将它升级为旧系统或产品业务定义。

## 固定且可重复的覆盖

- 三节点含自环的全部512个有向图，全部端点对、深度1–3：13,824次比较。
- 四节点不含自环的全部4,096个有向图，全部端点对、深度1–4：262,144次比较。
- 固定种子298生成32个六节点图，每图26条含平行边的合成边。节点ID包含
  非ASCII和字典序不同于数字序的值，边包含规则标签及纳秒时间边界。
  四种规则集合、三个半开时间窗口、全部端点对、三种深度，并对原顺序和打乱顺序
  各校验一次：82,944次比较。另对两种顺序各经公开 `EvaluateJSON` 执行，768次比较。

总计358,912次核心结果比较、768次JSON入口比较。图大小及固定种子只是有限、
可重复的测试输入，不是产品容量、随机分布保证或对任意大图的形式证明。
32个样本不会穷举所有平行边、规则和时间组合；生产大图资源与完整真实链路仍有
独立门禁。既有最大深度/节点/边数量测试保留，不以小图参照替换它们。

## 负向对照

`scripts/verify_attackpaths_oracle_mutations.py` 先确认未修改算法的新增测试通过，
再在独立临时目录生成7份单点错误版本，通过 Go `-overlay` 仅改变本次编译看到的
源文件，不写入仓库生产源码。每个版本必须先编译成功，然后被新增参照测试拒绝：

1. 忽略规则过滤。
2. 错误包含结束时间边界。
3. 多允许一层深度。
4. 将深度未穷尽错误报告成无路径。
5. 反转目标节点的同长选择顺序。
6. 反转平行边ID选择顺序。
7. 将FIFO待遍历队列改成栈顺序。

脚本只在上述已声明源码片段仍唯一时运行；源码变化导致匹配不到或匹配多个时失败，
不猜测替换位置。编译失败、测试全通过、超时或非预期失败都不算成功发现变异。
每次编译/测试上限120秒用于防止验证进程无限等待；删除上限可能让验证挂起，
慢机器超时则需要调查而不能算通过。结束时再次核对原源码逐字未变。
临时文件只包含本仓库合成测试算法，不访问真实AD、凭据或外部服务。

## 复现与剩余门禁

使用仓库要求的 Go 1.27.1，已缓存依赖时可离线运行：

```sh
export GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off
go test -race -count=1 ./internal/attackpaths ./cmd/adtr-attackpaths
go test -count=1 -v ./internal/attackpaths -run 'TestShortest.*Oracle'
python3 scripts/verify_attackpaths_oracle_mutations.py
```

离线环境变量阻止工具链、模块代理和校验数据库的网络请求；缺缓存会失败，
不会临时下载。模块仍按现有 go.sum 进行本地校验，不声称本轮完成远端校验数据库
核验或依赖审计。这些不是部署配置，也不修改依赖文件。
脚本使用 `GO` 指定的单个可执行文件，缺省为PATH中的 `go`，用于选择已验证工具链。

原有Go测试入口会自动包含新增测试；变异脚本是额外手动验证，不替代任何现有检查。
受当前限制，不运行 npm audit 或包含它的 make check、不创建PR、不触发CI。
离线测试与独立复审不能替代精确发布head的全部检查、目标main兼容、合并后验证、
真实数据库/浏览器/AD/Windows验收。#44保持开放，产品验收仍0/209。
