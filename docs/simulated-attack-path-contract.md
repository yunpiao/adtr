# 合成事件关系路径核心 v1

## 结论与范围

本切片提供 **明确合成的、内存内的有向事件关系路径查询**，作为
[Issue #44](https://github.com/yunpiao/adtr/issues/44) AD-F-117 的工程准备。
基线 main `6f1a15b876c75776688de6a104c213a2b01ffc1a`。
它没有建立攻击规则、有效权限、可利用性或时间因果关系；查询得到的路径仅证明
调用方提供的合成边之间存在连接。Issue 保持开放，产品验收仍为 0/209。

已经核实的需求线索：FLD-1745–1752 描述域、1–300 条规则、时间、名称与分页输入；
FLD-1753–1766 描述列表和计数。原始语义未冻结。当前仓库已有 groupgraph，但其
组成员边不等于攻击边；本模块不转换组关系、不读取真实 AD、也不调用现有检测器。
本切片的算法和下面的参数都是显式工程假设，不是旧系统行为兼容声明。

只有三个新增文件：`internal/attackpaths/graph.go`、同目录测试和本文档。
没有 API、CLI、Worker、数据库、迁移、前端、外部连接、鉴权接线、权限配置或 CI 改动。
它不实现 AD-F-095 规则信息查看或 AD-F-118 XLSX 导出。

## 输入与快照

Build 必须接收版本 `adtr.simulated-attackpaths.v1`、simulated=true、非空
TenantID/DomainID/ObservationID。Scope 是调用方声明的标签，不是认证或授权证明。
每个节点包含唯一 ID 与 Name；每条有向边包含唯一 ID、现有起终点 ID、规则标签、
非零 UTC 时间。缺失节点、重复节点/边 ID 和非法字段使整个构造失败，不返回部分图。
自环、环、多条平行边和空图允许；平行边必须有不同的证据 ID。

标识符/规则/范围/观测 ID 限 128 Unicode 码点，名称限 256。必须是合法 UTF-8，
无控制字符、无首尾空白。保留原文，不 trim、不大小写转换、不 Unicode 规范化。
时间年份为 1–9999，零时间不支持，时区偏移必须为零；构造时统一存成 UTC。
这些是 Go 值接口，不提供 JSON 解码器或 HTTP 请求校验。

节点上限 4096，边上限 16384。两个限制都必需，用于限制内存和每次遍历工作量；
删除限制会放大资源消耗。其副作用是拒绝更大的合法业务图，不能作为产品容量验收。
图构造和查询均复制切片，构造后图不可变，支持并发只读调用。

## 查询与结果

Shortest 的 Scope 必须与构造 Scope 精确相同，否则 ErrScope。此检查只防止调用者
混用合成数据，生产接入仍必须重新设计认证、当前权限和租户/域数据来源校验。

- From/To 必填且必须存在，否则分别返回 ErrInvalid 或 ErrNotFound。
- RuleIDs 必填，1–300 个非空且精确唯一的规则标签。未知标签匹配零条边，不执行规则。
  上限源自需求线索，匹配方式为模拟假设。删除必填要求会引入不明确的全规则语义；
  删除上限会增加处理成本。严格拒绝重复项可能与未来产品定义不同。
- Start/End 必填、UTC、非零且 Start < End。只包含 `[Start, End)` 内的边。
  半开区间避免相邻窗口重复计数，但会排除恰在 End 的边；不是旧系统端点语义证明。
- MaxDepth 必填，范围 1–64，按边数计数。这使查询的深度边界明确；去掉会允许更深的
  图搜索。副作用是超过边界的候选会得到 ErrLimit，而非无路径结论。

采用 FIFO 广度优先遍历；相邻边按目标节点 ID、边 ID 的 Go 字符串顺序排列。
返回一条确定的最短有向路径。相同长度下按上述遍历顺序选择，不依据时间、风险或
规则优先级。节点和边均保留原始证据；每个成功结果带版本、simulated、Scope、
ObservationID。同一节点到自身是零边路径，不证明有攻击或事件发生。

Found=false 表示过滤后完整遍历了从起点可达的图且没有目标；两数组为空 []。
它仅说明该合成快照，没有证明真实环境安全或数据完整。若达到深度上限后仍有未访问
邻居，则返回 ErrLimit 和空 Result，不把未探索部分报告成没有路径。
查询在找到目标后结束，因此无关分支触及预算不会遮蔽已找到的最短路径。

**时间只是逐边过滤，不强制路径事件按时间递增。** 连接不等于因果，图不表示真实可
执行攻击链。生产使用前需独立定义关联、规则、证据可信性、完整性与时间语义。

## 验证与剩余工作

测试覆盖稳定最短路径、平行边/输入顺序、自环和环、半开时间边界、规则过滤、无路径、
深度超限、零边路径、范围错配、未知节点、空图、输入/输出复制、非法字段、边/节点
上限与并发读取。最大输入测试只证明规定大小的合成数据可运行，不等于吞吐/容量验收。

尚缺规则目录和可信事件生产者、持久化、HTTP/浏览器链路、授权审计、分页/名称查询、
图谱显示、XLSX 导出、真实 AD/八类 Windows 和端到端验收。上游 F13/F21/F29/F38/G04
未由此补齐，不关闭 #44，也不增加产品验收计数。
