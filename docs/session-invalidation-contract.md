# 浏览器跨标签会话失效契约

- `/api/auth/me` 是身份与会话的唯一读取依据；跨标签消息只携带有长度上限的随机失效 nonce，不携带用户、资料、令牌、凭据或操作内容。
- 本标签确认登录、退出、密码或 MFA 会话变更成功后，发送同源 BroadcastChannel 消息及立即删除的 localStorage nonce。读取状态、接收通知与不确定写入结果不广播；重复通知有固定容量去重。
- 收到通知先中止旧请求代际、卸载私有界面并清除会话证明，再核验真实 `/me`。延迟旧响应不能恢复旧身份；核验失败不能展示旧资料。
- 标签重新获得窗口焦点或变为可见时补核验；普通输入焦点不触发。身份及会话未变时尽量保留草稿；变更或核验失败则卸载私有界面。
- 保留按真实 actor 隔离的不确定变更恢复记录，只允许重新查询核对，绝不自动重放写入。组件卸载时关闭频道、移除监听器并中止在途核验。
- 验证覆盖延迟响应、跨标签退出再登录、频道或存储不可用、失败关闭、重复消息、卸载及焦点/可见性回归。真实浏览器/API/数据库证据单独记录。

基线：本切片开始于 a29d81f；前序 F56 `make check` 430 项通过（本地记录 `/tmp/adtr-operational-make-check-final.log`）。本切片的执行结果待完成后补记。

实现结果：通知路径立即卸载私有页面，失败的核验不能恢复旧身份。焦点/可见性核验期间主内容 hidden/inert；同一身份及 CSRF 会话保持表单草稿，已退出状态的再次401也保留未提交登录草稿。身份、角色/权限值、CSRF或强制改密状态改变则清除旧表单。品牌导航或旧子请求不能绕过正在进行的核验。

任务、审计、维护和域检测恢复记录使用 actor ID＋用户名隔离，跨会话轮换及另一账户访问保留非敏感未知结果记录。会话失效仅解除活动绑定；存储不可用时保留内存中的已尝试记录。明确解决/放弃只删除捕获的原actor和操作键，旧格式迁移不能使已完成记录重新出现。源凭据和日志包的既有actor隔离规则继续生效。

本地验证：完整 make check 通过482项DOM测试（新增11项会话回归、41项恢复记录回归）、Go race/vet/build、5项Python契约及依赖审计0漏洞；独立源码审查完成。真实跨标签浏览器用例使用实际账户/API响应延迟、真实聚焦/可见性事件，并禁止旧标签自动POST。类型及测试发现检查已通过，真实浏览器/API/PostgreSQL执行尚未完成。该用例不替代B2特定凭据来源或打开使用屏障验收。
