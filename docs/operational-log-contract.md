## Journal and runtime boundary

The journal, immutable bundle producer and authenticated HTTP adapters share the exact application schema version. Schema14 introduces their tables; historical migration constants remain reproducible. Installation owner is the existing F52 owner tenant, default.

Event exact fields: schemaVersion=1,eventId,processId,module,code,outcome,severity,reason,observedAt,recordedAt. IDs are server-generated UUIDs; processId MUST NOT reuse a task lease owner. No metadata map. Code/outcome/reason whitelist: service_start_requested/attempted/empty; service_stopped/completed/empty; service_failed/failed/serve_failed or worker_failed; queue_cycle, recovery_cycle, scheduler_cycle with completed or failed (reason cycle_failed); queue_progress/progress/empty. Severity info except failed=error. api only service codes; worker supports all. Observed time captured by Emit, normalized UTC microseconds; recordedAt is insertion timestamp in a committed transaction, not claimed exact commit time.

EventStore.Append(ctx,event,RecorderObservation)(Event,error). NewRecorder(EventStore,Module)(*Recorder,error); Recorder.Emit(code EventCode,outcome Outcome,reason Reason) bool; Start(ctx) error atomically starts the owned loop; Run(ctx) error remains available for direct lifecycle use; Close(ctx) error; Stats() RecorderObservation. Queue128 plus one pending event, nonblocking Emit, immutable event identity/content through retries, each store attempt2s, capped retry backoff. Same event replay returns original recorded row; conflicting content rejects. Separate definite rejected/queue-full counts from unacknowledged outcomes after uncertain commits; never call an error persisted success. Reports are explicitly incomplete/stale observations, not complete delivery or live health. Close stops acceptance, drains up to supplied5s context, aborts active context and joins cooperative production writer. The command owns the background recorder context and closes it after producer shutdown; no timer manufactures events. Worker observations arrive through existing5s same-status coalescing and may represent empty polls, not business tasks. All crash gaps remain possible. No automatic purge or total-capacity claim.

## HTTP

GET /api/system/logs; GET /sources; POST /bundles; GET /bundles/history; GET /bundles/detail?taskUUID=; GET /bundles/download?taskUUID=; POST /bundles/cancel (all suffixes relative to /api/system/logs).

Only installation-owner tenant default, current authenticated identity and system.readable+system_logs.readable can read. Custom roles default-denied new system_logs. Submit/cancel additionally system_logs.writeable+tasks.readable/writeable, Origin/CSRF and fresh password/unused TOTP. Dedicated package reads do NOT require tasks.readable; generic task routes retain their normal grants. All success responses including bytes carry X-ADTR-User-ID; no-store/nosniff. Exact schema gate before auth/rate/bookkeeping. Reject client tenant/userInfo/src/fileName or unknown/null/duplicate fields.

GET log query: pageIdx default1,1..1000000; pageSize default20,1..100 or -1 only page1 with authorized total<=1000. systemType repeated distinct api/worker, omission means both. startTm/endTm both absent or both supplied, explicit-offset RFC3339<=6 fractional digits, canonical UTC, start<end, max24h. Absent bounds resolve once from DB-now minus24h to DB-now. Filter recordedAt half-open, order recordedAt DESC,eventId C DESC. One statement for window/count/page/coverage. Echo resolved selection so UI can explicitly reuse it. Unsupported legacy module rejects the entire request.

Response List: {page:{pageIdx,pageSize,total,totalPage},List:[{event:Event,log:string}],exhausted,selection:{startTm,endTm,systemType},coverage:Coverage}. log is JSON of identical Event. Coverage: {mode:"best_effort",gapsPossible:true,journalCreatedAt:UTC string,firstRecordedAt:UTC string|null}; no empty result implies complete coverage. Sources: {modules:[{module:"api"|"worker",registered:true,firstRecordedAt:string|null,lastRecordedAt:string|null,recordedCount:number}],coverage:Coverage,reports:[RecorderReport]}. RecorderReport carries processId,module,startedAt,observedAt,accepted,acknowledged,rejected,queueFull,writeFailures,unacknowledged,abandoned,acceptanceStopped,reportedAt and evidence=incomplete_process_observation. Counters are observations taken before the currently acknowledged append, not complete delivery totals. Sources also returns reportsTruncated and caps reports at100. No inferred current health.

POST bundles exact fields startTm,endTm,systemType (explicit nonempty array),idempotencyKey,actorPassword,totpCode. Required range max24h. Validate/canonicalize modules as sorted set. Snapshot captured at execution, not earlier list membership. Same intent/key replay never starts another task; use existing proof rules (fresh proof per POST, read recovery via history/detail). Response {taskUUID,task:publicTask,replayed}.

POST cancel exact taskUUID,actorPassword,totpCode; owner check plus live write permission. Response {task:publicTask}. Unknown commit must read existing task, never generate replacement key automatically.

Bound event/manifest/chunk sizes. Fence-specific immutable chunks/manifests, no publish before successful fenced terminal state. Cancelled/stale worker cannot expose staged output.
