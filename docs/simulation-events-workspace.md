# 合成安全事件工作台（#254）

该切片把合成模型接到真实 PostgreSQL、会话授权、HTTP 与 React；不连接真实 AD。
所有事件必须来自明确的 synthetic fixture，独立 simulation_event_* 表，不混入目录观测。
页面显示来源和模拟标识；无数据时展示空状态，不伪造“已采集”数据。

## 启用与权限

`ADTR_SIMULATION_EVENTS_ENABLED=true` 仅开放该入口，默认关闭；只在隔离测试中启用。
该参数用于独立关闭未真实验收的模拟工作台，入口可用时必需；删除后失去独立关闭边界，
开启后的副作用是提供额外受保护路由，但不会导入数据或给任何角色授权。
部署和现场配置不属于本次代码交付。

新的 simulation_events 功能权限默认拒绝，包括 platform_admin；迁移只扩展许可 mark 的
CHECK 约束和撤权序列机制，不给现有角色添加权限。读取需要显式 readable，变更还需
writeable；每次请求重新验证会话、当前 tenant/domain 资源范围，POST 还检查 Origin/CSRF。
前端仅以 /auth/login 与 /auth/me 的可选 simulationEventsReadable 提示决定菜单显隐；缺失为 false。
提示不授权，工作台另查服务器 menu/check，所有数据路由独立验证真实当前权限。

数据库版本24由显式 migrator原子创建，运行时不自动迁移。删除新表/降级不在本切片范围。
合成 fixture 只由测试入口种入隔离数据库，没有通用网页上传入口。

## 交互与持久化

路由 #simulation-events；通过当前授权域选择器选域、加载数据集，再查询/查看详情及标记/关闭。
查询使用固定分页和时间边界。case清单属于数据集，不等于筛选事件的命中结果。
变更携带 expectedRevision 和唯一 operationId；服务器锁定case，在同一事务提交状态、
不可变变更记录、平台审计和回执。原ID相同请求优先返回原回执，不重复追加状态变更。

连接中断时先读取原回执；未找到时先重新验证原作用域和对象，再使用完全相同ID/请求重放。
客户端不把版本已经前进当成“原操作失败”的证明，服务器回执优先解析迟到的原提交。
身份、域或授权改变时清除受保护结果，迟到响应不能覆盖新的选择；取消和重复点击有独立保护。
成功响应必须绑定当前actor响应头；未确认的操作不能换新ID盲重试。
