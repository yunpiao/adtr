## 队列连续性与清理

筛选编辑稿与已应用查询分别保留，页码和最后查看行只存在当前域工作区内存。返回列表重新读取 API 后才恢复行焦点；行已不可见时聚焦队列标题。读取期间不显示旧列表，旧请求由现有请求代次/AbortSignal 清理。未应用编辑稿不会成为实际查询。

App 仅对 domains→domains 的历史导航复用现有 focus/visibility 会话验证：旧页面在请求期间 hidden/inert，身份变化清除私有工作区，重复 popstate/hashchange 请求保留现有中止与序列隔离。其他路由继续原刷新策略。历史导航回到安全队列，不重开凭据表单或恢复密码。离开工作区、身份/会话变化与页面重载会清除队列内存；持久回执仍按原契约单独隔离。
