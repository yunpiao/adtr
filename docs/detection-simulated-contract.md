# 声明式检测模拟契约 v1

## 结论与范围

本切片提供可真实执行的**离线合成规则内核**，不是已确认的业务算法或生产检测。
依据是用户授权“缺少依据，先模拟一个依据”，结合 requirements/catalog.json 的
AD-F-088（测试）、099（条件）、100（生成）、102（配置检查与测试）拆出可验证子集。
模拟契约标识为 `adtr.detection.simulated.v1`，来源标识固定
`synthetic-business-contract-2026-11-01`。两者必须出现在规则输入和匹配输出；
事件必须包含同一来源标识。这些标签防止意外混淆，不证明调用者的数据真实来源。

**不计为这四项完整交付，更不计 AD-F-086–102 全部完成。** 未实现列表/CRUD、
规则库、持久化版本、发布审批、激活流程、UI、生产授权/任务接线、学习型检测、
攻击路径、采集、通知或响应；Enabled 只控制本次内核是否执行规则。
产品验收仍保持现有台账数值，不因模拟测试通过改变。

## Go 接口与确定性

- `Compile(scope Scope, rules []Rule) (*Program, error)`：完整检查每条规则，
  对条件和值深复制，生成 SHA-256 摘要，得到不可变、可并发读取的 Program。
- `(*Program).Evaluate(ctx context.Context, events []Event) ([]Match, error)`：
  先检查全部事件，再按事件输入顺序、规则输入顺序求值。
  输入错误、取消和结果溢出都返回 nil + error，不返回部分成功。
- 所有结构使用 JSON tags，命令层可复用；本包没有 JSON 解析器、HTTP 入口或持久化。
  接入层必须限制原始输入大小、严格解码、检查重复/未知键，并验证调用身份权限。
- Scope 是调用者显式提供的 tenant/domain。所有规则和事件必须逐字匹配，
  跨租户或跨域失败；这里是输入一致性检查，不能替代服务端授权。
- 摘要覆盖固定字段 JSON 序列化的完整规则，包括版本、作用域、启用位及条件顺序。
  相同输入可重现摘要，修改版本改变摘要；语义等价但顺序不同不承诺同摘要。
  Version 必须大于 0，由调用者提供；内核不声称提供跨调用单调版本或审批证据。
- 调用者不能在 Evaluate 期间并发修改事件 map；Program 已脱离原始规则所有权。

## 模拟条件语言

字段闭集：event.code、event.category、event.outcome、actor.name、target.name、
source.ip、object.kind。全部为 UTF-8 字符串，**不将 source.ip 当网络目标，
不解释 IP、事件编号或用户名的领域含义**。

操作符：
- eq / neq：区分大小写、逐字比较，一个非空值。
- contains / prefix：字面子串/前缀，一个非空值。
- in：1–32 个候选值，逐字比较。
- exists：零个比较值，只检查字段存在。
- Combine=all / any：非空、单层 AND / OR，无递归表达式。
- 缺失字段对所有操作符都为 false，包括 neq；缺失证据不推断异常。
- 空字段值拒绝，缺失字段用省略表示。未知字段或操作符拒绝。
- 没有正则、脚本、模板、SQL、shell、网络或文件访问；代码样式字符串只按字面比较。

## 必需参数、预算和副作用

Contract/Provenance 必需，用于隔离契约版本和合成结果；删除导致拒绝。
Scope/ID/Version 必需，用于归属、去重和版本追溯；缺失或非法导致拒绝。
Enabled 默认 false（未填不执行），避免意外启用；true 仅令本次离线求值生效。
Combine/Conditions 必需，避免空规则匹配一切。Conditions 空列表拒绝。
事件 Fields 可为空，表示没有可检测字段，不代表收集成功。

预算为本模拟实现选定，尚无生产容量依据：
128 条规则、每条 32 条条件、in 最多 32 个值、单值最多 512 字节、
每批 1000 个事件、最多 10000 条命中；ID/Scope 字段最多 128 字节。
所有文本必须有效 UTF-8，拒绝 ASCII 控制字符。规则/事件 ID 在各自批内唯一。
预算不可由输入上调，移除预算会增大 CPU/内存耗尽风险；副作用是合法大批次需
由上层有界分批，结果超额会整批失败，不能把失败当成“未发现威胁”。
不存在跨批去重、时间窗口、聚合、评分或事件顺序推断。
本包输入已经是 Go 对象，不能防止调用者在调用前分配超大对象；
原始字节预算必须由接入层负责。

ErrInvalid=格式/闭集/标识错误，应修改输入；
ErrScope=作用域不一致，应核对授权后的目标而非放宽范围；
ErrLimit=超预算，应缩小批次或收紧规则，不能自动省略结果；
context.Canceled/DeadlineExceeded=未完成本次求值，应由调用者决定是否重新执行。
错误不包含原始规则或事件字段，匹配不复制敏感事件字段。

## 验证记录

基线：实现前 `go test ./internal/detectionrules` 因包不存在失败，未冒充通过。
实现后使用 README 指定的已恢复 Go 工具链：

```sh
source ../adtr-recovered-toolchains/dev-env.sh
go test -race -cover ./internal/detectionrules
go vet ./internal/detectionrules
```

测试覆盖所有操作符正负例、缺失字段、AND/OR、停用、固定来源与版本摘要、
源规则修改隔离、并发求值、重复ID、跨租户/域、未知/恶意操作符、
控制字符/非法UTF-8、字面代码字符串、各主要数量边界、
零值 Program、确定性顺序、取消及超额结果原子失败。
另有 FuzzLiteralEquality 验证任意输入字符串不逃逸字面求值。
测试数据全部合成，不连接真实 AD、不读取凭据、不产生外部副作用。
该记录仅涉及本包测试；完整仓库 CI、数据库/浏览器和真实 AD/产品验收需单独证据。
