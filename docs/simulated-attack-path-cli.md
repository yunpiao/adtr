# 合成事件关系路径离线 JSON 查询

## 结论与范围

[工程 Issue #274](https://github.com/yunpiao/adtr/issues/274) 为
[#44 / AD-F-117](https://github.com/yunpiao/adtr/issues/44) 的已有内存核心增加
可运行、严格有界的离线输入。基线 main `93f8c4d62b99370a69af7db057ab17bcfab27e2f`。
算法、图上限和业务假设保持[核心契约](simulated-attack-path-contract.md)不变。
结果只证明调用方提供的合成边之间有连接，不证明可利用性、攻击、时间因果或真实环境安全。
没有真实 AD、数据库、API、权限接线、Worker、前端图谱、XLSX 导出或产品验收；0/209 不变。

这是独立程序，不读取 ADTR 环境配置。只有标准输入、标准输出、标准错误 I/O，
不打开输入路径、不写应用文件、不连接数据库或网络、不执行规则。
Scope 仍是调用方自报的标签，其匹配不能替代身份认证和当前域授权。
运行命令以及 shell 重定向读写的是操作者自行选择的本地文件。

```sh
go build -o bin/adtr-attackpaths ./cmd/adtr-attackpaths
./bin/adtr-attackpaths < examples/attackpaths/request.json
```

示例全部使用合成标识；预期 `found=true`，三个节点、两条边，
边 ID 依次 `event-1`、`event-2`。输出包含 `version`、`simulated=true`、Scope
与 ObservationID。单次输入、单次输出，不接受命令行参数。
`make build` 继续只构建服务入口；离线工具用上述独立命令构建。

## 完整输入契约

根对象必须且只能包含 `snapshot` 和 `query`，内部字段名与核心 Go 值的 JSON
标签一致。所有字段必填且不能为 null，包括节点/边空数组。允许任意字段顺序，
拒绝所有层级的未知键、重复键（含转义后相同的键）、大小写别名、错误类型、
非法 UTF-8、未配对 Unicode surrogate、额外 JSON 值或尾随垃圾。
合法 surrogate 对、转义反斜线和真实 U+FFFD 字符允许；标识仍受核心标签校验。

- `snapshot.version` 必须是 `adtr.simulated-attackpaths.v1`，`simulated` 必须为 true。
  `scope` 包含 tenantId/domainId；observationId 必填；nodes 和 edges 使用核心字段。
- `query` 必填 scope、from、to、ruleIds、start、end、maxDepth。maxDepth 只接受
  JSON 整数词法，不接受字符串、2.0 或 2e0；有效范围 1–64。
- 所有时间必须是非零、年份 1–9999 的规范 UTC RFC3339Nano 字符串，以 Z 结尾。
  无小数或最多九位小数且末尾非零，例如 `2026-11-01T10:00:00.123Z`。
  拒绝 `+00:00`、非 UTC 偏移、逗号小数、冗余小数零和超纳秒精度，避免解析时
  静默精度丢失或多个字符串代表同一时刻。这个限制只适用于新增 JSON 边界，
  不改变原 Go 值接口。副作用是调用方需要先规范化其他有效 RFC3339 表达。
- 时间窗仍是 `[start,end)`；规则精确匹配；时间只过滤每条边，不要求沿路径递增。

## 资源限制与失败语义

输入总字节上限 8 MiB，包含空白；CLI 最多读取 8 MiB + 1 字节用于判定超限。
这个限制用于限制输入分配和解析工作，在任何 CLI 使用下都必需；去掉会允许无界
读取。副作用是各节点、边、标签同时达到各自最大值的图可能被总字节限制拒绝。
输入流必须结束；字节上限不提供墙钟超时，等待未结束的 stdin 可能持续阻塞。

节点 4096、边 16384、规则 300、深度 64 的核心上限保持；JSON 解析在超过数组
条目上限时立即拒绝。所有限制共同生效，均是工程保护，不是已验收产品容量。
解析结构由固定 schema 限制，不接受任意层级对象。

- 退出 0：查询成功，输出一个 JSON 对象和换行。`found=false` 只表示完整遍历
  这个过滤后的合成快照仍无路径，nodes/edges 都是空数组。
- 退出 1：输入、Scope、节点、预算或读写失败。深度不够是 `budget exceeded`，
  不输出 `found=false`；应在允许的 1–64 范围内调整深度或明确缩小查询，不把
  未探索部分当成无路径。Scope 错配应修正输入标签，不能将此当作权限批准。
- 退出 2：提供了命令行参数。使用标准输入重定向，不传文件路径参数。

验证/计算/序列化全部成功之前不会写任何结果；错误诊断只包含固定分类，不回显
输入值、路径或原始 I/O 错误。stdout 写入失败可能已发送部分字节，无法回滚管道；
调用方必须检查退出码，只接受退出 0 的完整 JSON。
