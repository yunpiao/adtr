## 2026-10-10 本地检查

`node prototype/adtr/test-static.cjs`：18 项通过。覆盖 JavaScript 语法、209/57 唯一追溯、classic script 文件存在、CSP 与无业务网络 API，以及受限 VM 中的：

- 管理员无默认域访问；无权限场景的对象、任务、数量和审计选择器拒绝
- e2 服务身份和 e3 组对象跨事件/响应/任务的精确目标保留
- 重复提交意图去重，响应目标快照保留
- 审计行与导出按当前域过滤，无管理员域绕过
- 旧 epoch 未知结果不得重新变成成功
- 单次类型、部分失败无通用恢复
- 下载撤权不随切域或场景变化而撤销
- 跳到主内容与更新焦点保护的源码约束

VM 和源码检查不证明真实键盘/焦点、网络或浏览器行为。

## 独立浏览器脚本

`test-browser.cjs` 包含 33 个场景，待 GitHub 标准 runner 实际执行。覆盖九页、资产筛选/详情、e2/e3 响应、重复 Enter、排队/运行取消、取消竞争/失联、未知核对、撤权重授、失败恢复、部分失败、v2 三条件、域权限/审计隔离、消息计数、CSV/撤销、权限确认、历史/跳转、表格/抽屉/报告更新焦点、窄屏、file 直开及全程静态资源白名单。

1. `01-overview.png`：桌面总览
2. `02-asset-detail.png`：资产调查抽屉
3. `03-response-confirm.png`：精确对象响应确认
4. `04-mobile.png`：390px 窄屏

这些是输出路径约定，不是已有截图或通过证明。CI 结果由实际精确提交补录，不能沿用 PR #88 的方案 CI。
