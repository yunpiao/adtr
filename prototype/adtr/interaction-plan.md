## 1 通用交互约定

### I00 页面与动作

- 进入页面：确认当前演示身份、租户、域范围、能力状态后显示内容；显示来源和时效。标题下面固定放“合成数据”说明。
- 查找对象：筛选→结果→详情→关联证据→回列表。搜索仅作用于当前范围；同名对象始终连同域和稳定 ID 区分。
- 编辑对象：打开→修改→字段校验→权限/范围复核→确认提交→等待→确定结果或结果待核对。取消编辑不等于撤销已经提交的更改。
- 批量操作：明确选择本页还是全部已筛选目标；确认前列出具体范围与数量。原型首轮建议只支持显式目标集合，不默示生产支持跨页“全选”。
- 危险动作：先显示效果及恢复限制，再执行演示二次验证和确认；演示验证不能被描述为真实 MFA。权限、目标版本或范围变化时丢弃旧确认并重新评估。
- 异步动作：提交确认后给出稳定任务 ID，允许离开后从工作中心找回；重复点击不重复创建。收到未知结果时保留关联 ID，先查询，不自动重放。
- 中断：关闭、取消、切页、切域、退出、跨标签身份变化都有明确的草稿/等待/任务区别；后退/前进只恢复允许的读状态，不重放写入。
- 外部效果：下载、通知、安装、响应、服务操作全部写“演示”；业务按钮不得实际触达外部目标。

### I01 权限与会话

页面可见、功能可读、功能可写、域范围、凭据用途、租户有效性、会话有效性分别是条件，不可由一个角色名替代。模拟模型覆盖：可读不可写、有功能无域权、有域权无功能、用途不匹配、禁用能力、租户过期、会话失效和撤权后恢复。

在演示“另一个标签切换身份”时，先移除旧私有内容，再加载新身份；旧请求返回不能重新显示旧列表、详情、草稿或下载地址。权限重新授予也不能让旧授权版本的任务继续执行或让旧确认自动提交。基线依据：[功能权限](../../docs/access-contract.md)、[资源授权](../../docs/resource-contract.md)、[任务授权](../../docs/task-authorization.md) 与 [App.tsx](../../web/src/App.tsx)。

## 2 关键闭环

### K01 登录并进入有效范围

关联 I-F42～I-F47。演示登录→首次/过期密码处理→MFA→有效会话→选择显式授权域→业务页面；另演示无域授权的管理员。

- 起点：无会话、需改密、正常会话三种固定夹具。
- 成功终点：可以明确知道当前身份、域和允许的动作。
- 异常：通用登录错误、限流、MFA 过期/重复、改密中断、会话到期、跨标签身份变化；重置密码不能移除目标 MFA。
- 返回/取消：强制改密只保留允许操作；取消等待后重新核验身份，不假定提交失败。

### K02 接入配置到目录观测

关联 I-F01～I-F05、I-F12、I-F47、I-F48。域配置→选择独立凭据用途或登记账户引用→显式用途授权→保存→连接诊断→查看任务证据→独立目录读取授权→目录观测。

- 连接配置保存、单次诊断成功、当前在线、目录读取、采集器安装是五个不同结果。
- 域资料可演示未配置凭据；账户维护权不自动授予使用权。v1/v2 授权和凭据用途彼此独立；v2 必须同时打开 `ADTR_DIRECTORY_READ_ENABLED` 总开关与 `ADTR_DIRECTORY_READ_V2_ENABLED` 附加开关，且具备当前独立 v2 授权/凭据用途。两个开关默认关闭，诊断成功不会开启读取。
- 异常：域配置版本变更、无范围、用途未授权、TLS 失败、默认关闭、租户超限/过期、账户仍在使用。
- 凭据使用终态与执行结束证明分别展示；取消/解绑/超时都不能直接解除“待确认停止”依赖，不提供强制释放按钮。
- 成功终点：目录观测注明批次、采集窗口、支持字段和真实缺失值；缺席对象不得自动显示为已删除，批次不是 AD 时间点快照。

### K03 资产调查到关联证据

关联 I-F12～I-F17、I-F29、I-F30、I-F33。筛选用户/计算机/组→详情→组/权限/信任关系→行为时间线→关联威胁→证据。

- 页首始终显示域、对象稳定 ID、数据批次和时效；列表返回恢复安全查询状态。
- 图形关系提供等价的边/节点列表；事实链接、推断路径和证据不足分开。
- 异常：同名对象、缺失 SID/mail/描述/时间、多值字段、旧批次、空关系、无权限、对象不可见；未知不变成“未发生”。
- 风险评分方法与重置效果未冻结，只展示带规则版本的合成评分；不能借原型给出真实算法或风险保证。

### K04 检测与规则发布

关联 I-F18～I-F28、I-F48、I-F49。选模板→选显式域→查看能力与耗时说明→提交演示任务→结果→复查→规则草稿→生成候选→测试→版本确认→演示发布。

- 检测不默认开启域写入、弱口令尝试或第三方泄露查询；这些仅展示待冻结的前提和合成结果。
- 不接受任意代码/命令。规则条件的有限字段、运算符及算法来源待各功能契约冻结。
- 异常：规则无输入、测试失败、无可判定夹具、不可用检测、计划冲突、版本变化和权限撤回；失败测试禁止发布。
- 成功终点：运行任务引用明确版本，后续编辑不改变历史证据。周期检测是规划交互；当前已实现周期计划仅覆盖基础设施健康检查。

### K05 威胁到受控响应

关联 I-F29～I-F32、I-F39、I-F48。事件列表→详情与原始证据→确认对象/域→查看阻断白名单→影响预览→演示二次验证→明确确认→任务→效果核对→必要时恢复计划。

- 确认区显示租户、域、对象类型/数量、动作、影响、可恢复性、白名单命中、证据关联；不只问“确定吗”。
- 响应按钮始终写明“演示”；事件关闭、规则例外、阻断及恢复不是同一种动作。
- 异常：权限丢失、目标变化、白名单命中、部分成功、未知外部效果、取消竞争、恢复条件不足。
- 不确定副作用先核对，禁止“全部重试”；部分失败只规划明确失败目标的独立新提交，并等待业务契约，不新增通用重放入口。
- 成功终点：事件、任务、逐对象结果和审计互相可追溯；恢复另有授权/确认，不能声称取消会撤销已经发生的效果。

### K06 任务到导出与追溯

关联 I-F37～I-F39、I-F48、I-F49。业务导出→确认筛选/范围/字段→任务→离开→工作中心找回→下载条件→演示文件→来源与审计。

- 任务成功与文件可下载分开；“可请求下载”不等于字节已校验或当前权限仍有效。
- 失败：权限撤回、文件过期/不可用、任务失败、部分结果、页面离开后结果未知。每次进入任务和下载动作都演示当前身份/范围重核验。
- 基线已有生产者是 Audit/XLSX；资产、事件、报告等业务导出在原型中只能标成规划演示，不能沿用审计切片的验证结论。
- 归档/还原只改变演示可见性，保留审计和任务关联；不展示“释放 X GB”。

### K07 采集运维与异常恢复

关联 I-F05～I-F11、I-F50、I-F56、I-F57。安装准备→包/系统兼容说明→演示注册→心跳→配置/采集开关→异常→诊断→升级/恢复方案→结果。

- 未观测、心跳过期、停用、故障、资源超限保护分别展示；忽略提醒不表示健康恢复。
- 批量升级有逐对象状态，不允许一行总成功掩盖失败；命令通道不提供任意执行输入。
- Windows 八版本实验、发行包签名/信任、远程协议、真实安装/卸载/恢复都未由原型验证。

### K08 权限变更与审计

关联 I-F45～I-F47、I-F39。用户/角色→功能权限→资源组→域范围→授权变化预览→演示新鲜验证→提交→受影响会话撤销→重新登录→审计。

- 非管理员不能越过自己的功能/域委派上限，不能修改自己的角色/关联规避限制。
- 自删、自禁用、移除最后启用管理员和向自己提权都应有明确拒绝场景。
- 租户配置和产品许可分开；保存过期租户配置可能禁用数据访问，确认页解释影响。

### K09 消息定位和通知配置

关联 I-F40、I-F41、I-F29、I-F48。消息列表→未读统计→消息详情→关联任务/事件→返回；通知配置→合成接收人→规则/模板关联→演示测试→延迟/计划说明。

- 未读数量基于同一身份和范围；消息已读不等于事件处理完成。
- 关联对象已无权查看时保留安全提示，不暴露其名称或旧详情。
- 通知发送必须永久标为模拟，不接收真实邮箱/手机号，不向外部发测试消息；通道及发送时序等待契约冻结。

### K10 平台健康与受控维护

关联 I-F52～I-F57、I-F38、I-F39、I-F48。系统资源→真实观测语义的合成示例→存储阈值→冲突确认→日志时间窗→打包→历史→演示下载；服务操作/部署单独展示影响和恢复条件。

- 采样时间、来源和未观测/过期/失败可见，不把 API 存活等同数据库就绪或业务能力可用。
- 日志只规划应用实际产生的事件类型，缺失历史来源显示不支持；不提供任意路径读取。
- 网络诊断不接受任意 URL；协议、端口、目标白名单是未决输入。服务启动/停止/重启、产品许可激活与安装不是已交付健康任务。

## 3 界面状态矩阵

所有列表、详情、表单、任务和高影响确认至少评审适用的状态。不适用必须写明原因，不能空白当作通过。

| ID | 状态/触发 | 用户看到什么 | 允许动作与验证要求 |
| --- | --- | --- | --- |
| S01 | 首次加载 | 有名称的骨架/进度，范围标题保留 | 可离开；旧响应不回填新页面；不闪现旧身份内容 |
| S02 | 初始无数据 | “尚无记录”及前置步骤 | 只向有写权限者展示创建入口；不得装成请求失败 |
| S03 | 筛选无结果 | 当前筛选摘要与零结果 | 清除筛选/返回；总数为授权后结果 |
| S04 | 请求失败 | 安全错误、关联 ID、可行下一步 | 只读可手动重载；写入先判断是否已确认未提交 |
| S05 | 无权限/对象不可见 | 统一安全说明，无私有残留 | 返回允许页面；直达、下载、浏览器返回同样拒绝 |
| S06 | 能力未启用/未实现 | “演示规划能力/当前实现不支持”及依赖 | 不显示虚假的执行按钮；与权限不足区分 |
| S07 | 字段校验错误 | 字段错误与汇总，保留非敏感输入 | 聚焦汇总/首错；不静默修正枚举、单位或密码 |
| S08 | 编辑版本冲突 | 新旧版本变化说明 | 重新读取后人工确认；仅有版本契约的模块才画 CAS，其他模块标明未冻结 |
| S09 | 提交中 | 锁定重复提交，描述当前阶段 | 可停止等待但注明不撤销提交；离开后能查找原任务 |
| S10 | 写入结果待核对 | “未确认结果”，保留安全关联 ID | 查询原意图/任务；不自动重放，不重新生成幂等键碰碰运气 |
| S11 | 排队/运行/等重试 | 状态、已知进度、尝试次数、最后更新时间 | 仅展示任务种类允许的取消/恢复动作；尝试与重投递区分 |
| S12 | 取消请求/停止未确认 | “已请求取消”或“停止尚未确认” | 不宣称已取消；显示核对步骤，无强制释放/伪完成 |
| S13 | 成功/部分失败/失败 | 真实场景结果，逐对象证据 | 成功不等于产品验收；部分失败不全量重试 |
| S14 | 会话到期/身份变更 | 私有内容立即移除，重新核验提示 | 禁止旧响应回填；敏感草稿清除；新身份不继承旧选择 |
| S15 | 未观测/陈旧数据 | 最后观测时间、批次、覆盖限制 | 可发起明确的新查询；无新证据不刷新成“健康” |
| S16 | 文件不可用/过期 | 原任务保留，原因明确 | 重新授权后再决定是否创建新导出；不提供旧下载地址 |
| S17 | 限流/服务不可用 | 安全说明和等待条件 | 不无限自动重试、不忙循环；保留可恢复的读状态 |
| S18 | 放弃草稿/关闭弹窗 | 说明草稿是否保留，危险动作未提交 | 返回触发点；后退/前进不复活弹窗或重复提交 |
| S19 | 租户过期/超额 | 与许可证区分的资源授权提示 | 业务数据拒绝；仅有权限者能进入契约允许的修复/撤销入口 |
| S20 | 依赖未释放 | 账户仍被任务使用，停止证明未完成 | 禁止更换/移除；终态、解绑、超时不自动解除 |

### 任务状态与界面状态不可混用

基线持久化任务状态是 `queued`、`running`、`retry_wait`、`cancel_requested`、`succeeded`、`failed`、`partial_failed`、`dead_letter`、`cancelled`。`completed-with-cancel-race` 是审计事件，`cancellation_unconfirmed` 是安全错误语义；“结果待核对”“会话重核验”“文件过期”属于界面或制品状态，不新增成任务成功状态。

| 当前任务状态 | 可演示转移 | 界面约束 |
| --- | --- | --- |
| queued | running 或 cancelled | 未开始时取消可确认；重复排队不增加实际执行次数 |
| running | succeeded / failed / partial_failed / dead_letter / retry_wait / cancel_requested | 只展示种类契约支持的转移；进度不能代替结果 |
| retry_wait | queued 或 cancelled | 明示下一次尝试时间和总次数上限；凭据/证书/授权/输入错误不自动重试 |
| cancel_requested | cancelled 或真实竞争终态；失联时 failed 且停止未确认 | 只有执行器返回后的事实才能确认取消，不把停止等待算作取消 |
| failed / dead_letter | 允许恢复的种类创建有父任务 ID 的新任务 | 重新授权、保留旧历史；SingleAttemptOnly 种类不提供通用恢复入口（包括手动 recover）；如需重做须按专用业务契约新提交 |
| partial_failed | 当前任务保持原结果 | 未来按业务契约选择明确失败对象新提交；不提供通用整任务恢复 |
| succeeded / cancelled | 保留终态，可在允许范围归档/还原 | 归档不修改事实，不移除审计或幂等记录 |

依据：[任务契约](../../docs/task-contract.md)、[实际任务状态](../../docs/tasks-contract.md)。无论原型状态切换器如何构造场景，不能把后端不允许的转移包装为既有能力。

## 4 逐功能组页面与交互清单

下表的“边界”是本组必须补充的负向场景，所有组还继承适用的 S01～S20、I00、I01。页面名称可在评审后调整，交互 ID 作为稳定追溯键保留。

| 交互 ID | 建议页面和原型路径 | 可评审操作 | 必须展示的边界或待冻结输入 |
| --- | --- | --- | --- |

import json
import pathlib
import re

interactions = re.findall(r'^\| I-(F\d{2}) \|', text, re.M)
